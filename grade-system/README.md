# Grade System

This project contains a simple Python program that takes a student's mark as input and prints the corresponding grade.

## How it works

The program asks the user to enter a mark between 0 and 100.

It then assigns a grade based on the following rules:

- 90 to 100 -> Grade A
- 80 to 89 -> Grade B
- 70 to 79 -> Grade C
- 60 to 69 -> Grade D
- Below 60 -> Grade E
- Any value outside the valid range -> Invalid mark

## Run the program

Open a terminal in this folder and run:

```bash
python3 marks.py
```

## Example

```bash
Enter the student mark: 95
Grade is A
```

- `marks.py` - Python script for the grade calculation
