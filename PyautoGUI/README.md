# Stock Price Automation using PyAutoGUI

## Overview

This project automates the process of:

1. Opening Google Chrome.
2. Searching for the Amazon, Apple, Microsoft, Nvidia and Google.
3. Copying the search result content.
4. Opening Microsoft Excel.
5. Creating a simple report with:
   - Date
   - Stock Price
   - Comments
6. Saving the report as an Excel file.
7. Taking a screenshot of the generated Excel sheet.

The automation is implemented using **PyAutoGUI** and is designed to run on **macOS**.

---

## Prerequisites

### Software Requirements

- macOS
- Google Chrome
- Microsoft Excel
- Python 3.x
