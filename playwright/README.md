# Cricbuzz Automation using Playwright

## Overview

This script uses Playwright to automate browser actions. It launches a Chromium browser, navigates to the Cricbuzz website, waits for the page to load, and captures a screenshot of the page.

## Functionality

- Launches a Chromium browser instance.
- Opens the Cricbuzz homepage.
- Waits for the page to load completely.
- Captures a screenshot of the webpage.
- Saves the screenshot with a timestamp in the filename.
- Closes the browser automatically after completion.
